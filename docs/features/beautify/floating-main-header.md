# 主页悬浮顶栏

入口：WeKit 设置 → 功能 → 界面美化 → 主页悬浮顶栏。

开启后，主页、通讯录和发现的顶栏替换为悬浮玻璃顶栏。原生顶栏容器、窗口分隔阴影和顶部磨砂带自动移除，无需另开隐藏选项。标题、搜索键和加号键继续使用微信原有控件和操作，只显示一套。

玻璃背景与按钮放在同一个圆角裁剪区域，卡片之外不保留原生矩形边框。列表顶部留出阅读空间，滚动时内容可以从卡片后方经过；玻璃采样列表内容，不采样顶栏自身。

点击功能可即时调整模糊强度、圆角、左右边距、顶部间距和重力高光。默认模糊强度为 8，圆角为 24 dp，左右边距为 12 dp，顶部间距为 4 dp，重力高光关闭。圆角和左右边距保留最小值，以保持悬浮外观。

切换到“我”或进入聊天时恢复原生顶栏，返回后重新应用。与悬浮底栏同时使用时支持其标签排序；启用主页侧滑面板后，顶栏随主页移动和缩放。关闭功能会恢复原生控件和列表留白；如宿主正在切换页面而未完全恢复，可重启微信。
