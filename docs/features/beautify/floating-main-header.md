# 主页悬浮顶栏

入口：WeKit 设置 → 功能 → 界面美化 → 主页悬浮顶栏。

将微信主页、通讯录和发现的共用顶栏显示为悬浮圆角液态玻璃卡片。“我”页面保留原生顶栏。系统状态栏和聊天标题栏不受影响。

## 外观设置

点击功能可以调整模糊半径、动态重力高光、圆角、左右边距、顶部间距和阴影高度。默认圆角为 24dp、左右边距为 12dp、顶部间距为 4dp、阴影为 4dp、模糊半径为 8dp，动态重力高光默认关闭。

模糊半径设为 0 时沿用共享玻璃组件的完全透明语义。动态重力高光会持续使用旋转传感器。

## 使用说明

四个主页标签复用同一个微信原生标题栏，切到“我”或进入内嵌聊天页面时，本功能会暂时恢复原生顶栏；返回其他三个标签后重新应用。

三个页面的列表可绘制区域延伸到悬浮顶栏背后，初始顶部留白让第一项保持可读，滚动时内容从玻璃后方经过。玻璃按页面实际位置采样，不将标题和菜单按钮采样进背景；无可捕获内容时使用半透明主题色降级。卡片外围的原生背景、顶部矩形磨砂带和横向阴影被移除，阴影仅沿卡片圆角绘制。

开启本功能后，微信主页的原生“微信”标题、搜索键和加号键自动隐藏，主页玻璃内不再显示或响应这些控件，无需另开隐藏开关。通讯录和发现仍保留各自的标题与操作。关闭本功能后恢复原生控件；若另外启用了[主页原生顶栏控件](home-header-controls.md)中的隐藏设置，对应控件继续按该设置隐藏。
