# 主页悬浮顶栏

入口：WeKit 设置 → 功能 → 界面美化 → 主页悬浮顶栏。

将微信主页、通讯录和发现的共用顶栏显示为悬浮圆角液态玻璃卡片。“我”页面保留原生顶栏。系统状态栏和聊天标题栏不受影响。

## 外观设置

点击功能可以调整模糊半径、动态重力高光、圆角、左右边距、顶部间距和阴影高度。默认圆角为 24dp、左右边距为 12dp、顶部间距为 4dp、阴影为 4dp、模糊半径为 8dp，动态重力高光默认关闭。

模糊半径设为 0 时沿用共享玻璃组件的完全透明语义。动态重力高光会持续使用旋转传感器。

## 使用说明

四个主页标签复用同一个微信原生标题栏，切到“我”或进入内嵌聊天页面时，本功能会暂时恢复原生顶栏；返回其他三个标签后重新应用。通讯录和发现的列表从标题栏下方开始，因此玻璃层从列表顶部采样内容，避免只显示着色底色；无可捕获内容时仍使用半透明主题色降级。

本功能只更换背景，不控制微信原生标题或菜单按钮。需要隐藏主页原生顶栏中的“微信”、搜索键或加号键时，使用独立的[主页原生顶栏控件](home-header-controls.md)设置；它不依赖本功能或“主页侧滑面板”。
