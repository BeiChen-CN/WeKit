# 主页原生顶栏控件

入口：WeKit 设置 → 功能 → 界面美化 → 主页原生顶栏控件。

可分别隐藏微信主页原生标题栏中的“微信”文字、搜索键和加号键，三个开关默认关闭。设置不依赖“主页悬浮顶栏”或“主页侧滑面板”；通讯录、发现、我和聊天界面保留各自的原生标题和按钮。

开启[主页悬浮顶栏](floating-main-header.md)时，主页的这三个原生控件会自动隐藏，不受本页开关是否开启的影响。关闭悬浮顶栏后，本页开关继续决定对应控件是否显示。

原“主页侧滑面板”的隐藏微信标题设置，以及之前“主页悬浮顶栏”的搜索/加号设置，会继续沿用已保存的偏好值，无需重新设置。切出主页或关闭对应开关时，会恢复原生控件的原有可见状态。
